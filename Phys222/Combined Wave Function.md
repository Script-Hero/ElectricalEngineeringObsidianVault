The solution to the [[Shrodinger Equation]] for [[Hydrogen Atom]] by combining the radial wave function $R$, found in the [[Radial Equation]] and the spherical harmonics $Y$ found in [[Angular Equation]] (and the [[Azimuthal Equation]]) to create the total wave function:

$\Psi_{nlm_{l}}(r,\theta,\phi)=R_{nl}(r)Y_{lm_l}(\theta, \phi)$
