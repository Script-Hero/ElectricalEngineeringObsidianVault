### Boundary Conditions
1. The wave function must be finite everywhere (to avoid infinite probabilities)
2. The wave function must have a *single value* per location (no multi-value probabilties)
3. The wave function and its derivative must be continuous
	1. Required because the second-ordered derivative term must be single-valued 
4. To normalize wave functions, they must approach $0$ and $x$ reaches $\infty$.

An example of a wave function that is **not normalizable** is $\Psi(x,t)=Ae^{i(kx-\omega t)}=A[\cos(kx-\omega t) + i\sin(kx-\omega t)]$
