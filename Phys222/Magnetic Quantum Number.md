[[Quantum Number]] $m_l$ -- related to space quantization -- can be any number between $-l$ and $l$
- Primarily determines elevation (or angle) of electron path relative to the nucleus
- *Used to describe the <ins>orientation</ins> of the object*


- the angle $\phi$ is a measure of rotation about the $z$ axis
- The solution for $g(\phi)$ specifies that $m_l$ is an integer and related to the $z$ component of $L$
	- $L_z=m_l\hbar$



#### *Example of relationship to other [[Quantum Number]]*
- Given $l=2$ (the [[Orbital Angular Momentum Quantum Number]]) 
- then $L=\sqrt{l(l+1)}\hbar=\sqrt{6}\hbar$
- Because $L_z$ is quantized, only certain orientations of $\vec{L}$ (orbital angular momentum itself, not the quantum number) are possible -- this is called **space quantization**

![[magnetic_number_space_quantization.png]]

- Quantum mechanics only allows $L$ to be *quantized* in 1 direction
		- [[Uncertainty Principal]]
- Because of the relationship $L^2 = L_x^2 + L_y^2 + L_z^2$ , the knowledge of a second component (beyond $L_x$) would give us complete knowledge of the third component, because we already know $L$ from before
- we expect the average of each component squared to be $\langle L_x^2 \rangle = \langle L_y^2 \rangle =\langle L_z^2 \rangle$
#### Therefore we find $\langle L^2 \rangle = l(l+1)\hbar^2$

Using this magnitude finding, (in the case of this example, we use $L_z=\sqrt{6}\hbar$), we allow the other vector directions $L_y$ and $L_z$ to change continually while $L_z$ maintains the fixed *quantized* value of $m_{l}\hbar$ as shown in this diagram:
