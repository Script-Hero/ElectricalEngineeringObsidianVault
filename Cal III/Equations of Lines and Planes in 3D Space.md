
## Vector Equation of Line:

We can have some function $r(t)=\vec{r_{0}}+ t\vec{v}$ which gives us points along the line. 

Consider that $\vec{r_0}$ is a "point vector", $\vec{v}$ is a "slope vector", and $t$ is the function input.

This function returns the *parametric equation* $<x_{0} + ta, y_{0} + tb, z_{0} + tc>$ where $\vec{v}=<a,b,c>$

- Consider that we can rearrange the above parametric equation to get:
	- $t = \frac{x-x_{0}}{a}$
	- $t = \frac{y-y_{0}}{b}$
	- $t = \frac{z-z_{0}}{c}$
- Each of these "3" $t$ values is equal to the others
