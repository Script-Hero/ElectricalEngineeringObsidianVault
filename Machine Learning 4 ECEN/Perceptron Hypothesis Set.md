We have defined a [[Hypothesis]] Set $H=\{h(x)=\text{sign}(w^Tx)\}$
- $H$ is uncountably infinite


$$
w=\begin{bmatrix}
w_{0}\\w_{1}\\ \vdots \\w_{d}
\end{bmatrix}\in R^{d+1},x=\begin{bmatrix}1\\x_1\\\vdots\\x_d\end{bmatrix}\in{1}\times R^d
$$

This hypothesis set is called the *perceptron* or *line separator*.
