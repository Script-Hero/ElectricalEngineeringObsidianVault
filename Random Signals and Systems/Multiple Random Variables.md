#Chapter7 
- If we have $n$ different [[Discrete Random Variable]]s of interest in a system we can index each one using $X_i$ 
	- Each with own [[Probability Mass Function]] $p_{X_i}$ 

- If 2 variables $X$ and $Y$ are associated with a single experiment, we can relate the random pair $(X,Y)$ by a [[Joint Probability Mass Function]]

- We can relate [[Conditional Random Variable]]s, the [[Probability]] of one [[Random Signals and Systems/Random Variable|Random Variable]] given another [[Random Signals and Systems/Random Variable|Random Variable]], using [[Conditional Probability Mass Function]]

- You may also have [[Functions of Multiple Discrete Random Variables]]
