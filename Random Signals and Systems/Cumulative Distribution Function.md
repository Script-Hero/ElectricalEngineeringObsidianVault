#Chapter8 
Cumulative Distribution Function (CDF) of [[Random Variable]] $X$ is denoted as $F_X(x)=P(X\leq x)$

- The probability that the outcome is $\leq x$. Accumulate probability *up to* the value of $x$. 
	- Monotonically nondecreasing
- If $X$ is a [[Discrete Random Variable]] $F_{X}(x)=\sum\limits_{k\leq x}p_{X}(x)$
- If $X$ is a [[Continuous Random Variable]] $F_{X}(x)=\int\limits_{t=-\infty}^x f_{X}(t)dt$
