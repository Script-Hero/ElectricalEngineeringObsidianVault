- Mapping from a virtual to a physical address 
- Page size = 2^12 = 4KiB
- Number of physical pages allowed in [[Memory]] is 2^(28) since the physical page number has 28 bits in it
- **This means the main [[Memory]] can have at most 4^40 = 1TiB, while the virtual address space is 2^48 = 2^8 * 2^40 = 256 TiB**
